How to preview:
1. Extract the ZIP file.
2. Open the soft-education-consultancy folder.
3. Double-click index.html, or open it in Chrome/Edge.
4. Use the navigation menu to visit all five pages.

How enquiry forms work:
- Forms validate required fields in the browser.
- On submit, WhatsApp opens with the enquiry details pre-filled for +91 91176 96512.
- The visitor must press Send in WhatsApp. No form data is stored in a database.
- To store enquiries, connect a secure backend/database or a trusted form service before publishing.

Before publishing:
- Confirm that the displayed business name, phone and founder details are correct.
- Add your official business email and office address if you want them shown.
- Add only verified college/company partners, vacancies, testimonials, credentials and placement claims.
- Replace or expand course options as needed.
- This is a static HTML/CSS/JavaScript site; it does not include an admin panel or backend.

Deployment:
Upload all five HTML files and the assets folder to your hosting provider's public web root (often public_html). Keep the folder structure intact.
